# SOC Command Center

A frontend SOC simulation platform built using React + TypeScript.

## Features
- Brute force attack detection simulation
- Incident lifecycle management
- Severity classification
- IP blocking workflow
- Investigation UI

## Tech Stack
- React
- TypeScript

- shadcn/ui
